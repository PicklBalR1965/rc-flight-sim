# rc-flight-sim

Browser flight and driving games around Doylestown, PA. They work on iPad, phone and computer.

| Game | Play |
|---|---|
| **Doylestown RC**: 9 RC aircraft over Doylestown (airport, downtown, Lake Galena, Camp Curiosity), with optional weapons and targets | [Play](https://fly.campcuriosity.com) |
| **Curiosity Campus Tour**: fly a trainer from Doylestown Airport over Camp Curiosity, Curiosity Academy and Doylestown Pickleball (autopilot available) | [Play](https://fly.campcuriosity.com/tour.html) |
| **Curiosity Campus Drive**: drive the campus in a 1973 MGB, an amphibious car and more | [Play](https://drive.campcuriosity.com) |

Each game is a single HTML file (Three.js from cdnjs).
